## Practice projects after the course

1. **Weather dashboard** — API, search, loading states.
2. **Expense tracker** — forms, totals, charts.
3. **Habit tracker** — dates, streaks, localStorage.
4. **Quiz app** — state machines, timers, scoring.
5. **Notes app** — CRUD, search, markdown.
6. **Movie search** — debounce, pagination, API keys.
7. **Kanban board** — drag and drop, columns, persistence.
8. **Pomodoro timer** — intervals, notifications, audio.
9. **Recipe box** — routing, filters, favourites.
10. **Personal portfolio** — design, deployment, writing.

Build the smallest complete version first. Then add one feature at a time.
